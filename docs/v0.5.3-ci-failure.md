# v0.5.3 Release CI Failure

The immutable `v0.5.3` tag was reproduced with the exact release workflow command:

```powershell
cd src/python
python -m unittest discover -p "test_*.py"
```

Result: 236 tests, 5 failures, 9 errors, exit code 1.

## Errors

1. `EventOverflowStressTests.test_overflow_10k_events_small_queue_slow_consumer`
   - Exception: `AttributeError: module 'time' has no attribute 'monotonic_start'`.
   - Cause: the test referenced a nonexistent module attribute instead of storing a local deadline.
2. `GlobalCacheLimitRealTests.test_dedup_shared_sha_counted_once`
   - Exception: `ValueError: invalid cache entry content_sha256`.
   - Cause: `shared` was embedded in a value that must contain exactly 64 hexadecimal characters.
3. `GlobalCacheLimitRealTests.test_lease_protected_not_evicted`
   - Exception: `ValueError: invalid cache entry content_sha256`.
   - Cause: the synthetic `lease...` value was not a valid SHA-256 and the lease was not linked to a real item.
4. `ProviderStateImportTests.test_duplicate_provider_reconciliation`
   - Exception: `ValueError: invalid clipboard provider state`.
   - Cause: the fixture attempted to build protocol metadata containing `offline`, but model validation rejected that state.
5. `ProviderStateImportTests.test_malformed_provider_ignored`
   - Exception: `ValueError: invalid clipboard provider device_id`.
   - Cause: the protocol builder correctly rejected the malformed fixture before the runtime import boundary was exercised.
6. `ProviderStateImportTests.test_offline_not_promoted_to_available_by_manifest`
   - Exception: `ValueError: invalid clipboard provider state`.
   - Cause: manifest model validation rejected `offline` before reconciliation ran.
7. `ProviderStateImportTests.test_offline_stays_offline`
   - Exception: `ValueError: invalid clipboard provider state`.
   - Cause: the announcement fixture could not encode `offline` through the model.
8. `ProviderStateImportTests.test_unconfirmed_stays_unconfirmed`
   - Exception: `ValueError: invalid clipboard provider state`.
   - Cause: the announcement fixture could not encode `unconfirmed` through the model.
9. `ProviderStateImportTests.test_unknown_state_falls_back_to_unconfirmed`
   - Exception: `ValueError: invalid clipboard provider state`.
   - Cause: the protocol builder rejected the deliberately unknown state before `_register_remote_providers` was tested.

## Failures

1. `EventThroughputStressTests.test_throughput_10k_events_1k_sequences`
   - Assertion: processed event count was not greater than 8,000.
   - Cause: a capacity-256 coalescing queue cannot retain that many rapidly submitted events without producer backpressure.
2. `GlobalCacheLimitRealTests.test_global_limit_enforced_after_excess`
   - Assertion: 209,715,200 bytes remained above the 104,857,600-byte expectation.
   - Cause: the test mutated a temporary normalized settings dictionary; subsequent runtime settings calls returned the unchanged limit.
3. `MetadataAnnouncementStressTests.test_5k_announcements_zero_payload_bytes`
   - Assertion: the receiver store contained zero items.
   - Cause: announcements were collected in a list but never delivered through `ClipboardManager.handle`.
4. `ProviderStateImportTests.test_available_stays_available`
   - Assertion: provider state was `None` instead of `available`.
   - Cause: the fixture omitted verified payload hash and size, so announcement parsing rejected it.
5. `ProviderStateImportTests.test_stale_stays_stale`
   - Assertion: provider state was `None` instead of `stale`.
   - Cause: an announcement whose announcing device was only `stale` violated the protocol requirement for an available announcing provider.
